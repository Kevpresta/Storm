# Storm

Storm est une simple application Android de capture photo orientée orage et éclairs.
Trépied obligatoire sur le smartphone pour une meilleure expérience. 

## Fonctions principales

- Capture manuelle avec ISO bas réglable et temps de pose jusqu’à 16 secondes.
- Mode chasse éclair avec détection de hausse lumineuse à deux niveaux.
- Selection des objectifs arriere, dont ultra grand-angle à l'infini.
- Capture JPG, RAW ou JPG + RAW selon les capacités de l'objectif.
- Aperçu cadre sur le rendu photo.
- Niveau numérique, minuterie, retour haptique et son discret de prise de vue.

## Configuration

- Android Studio
- Kotlin
- Jetpack Compose
- Camera2 API
