# Storm

Storm est une application Android de capture photo orientee orage et eclairs.

## Fonctions principales

- Capture manuelle avec reglage ISO et temps de pose.
- Mode chasse eclair avec detection de hausse lumineuse.
- Selection des objectifs arriere, dont ultra grand-angle.
- Capture JPG, RAW ou JPG + RAW selon les capacites de l'objectif.
- Apercu cadre sur le rendu photo.
- Niveau numerique, minuterie, retour haptique et son discret de prise de vue.

## Configuration

- Android Studio
- Kotlin
- Jetpack Compose
- Camera2 API
